# 研究データ管理

更新：2026-10-12。公開リポジトリには原論文本文を無断転載しない。以下は初期の索引であり、網羅的・系統的レビューの完成版ではない。

## ファイル

- [sources.csv](sources.csv) : 文献の書誌、原典URL、調査範囲、確認日。
- [evidence-matrix.csv](evidence-matrix.csv) : 研究結果と候補機能を結び付ける一覧。
- [research-backlog.md](research-backlog.md) : 検証待ちの論点と次の調査。

## 出典の状態

- **未確認**: 候補として挙がったが、書誌情報・原典への到達を未確認。
- **書誌・抄録確認**: 出版社・PubMed・研究機関等のページで情報を確認。全文を精読した意味ではない。
- **全文確認**: 手法・参加者・アウトカム・効果量・限界を本文で照合。
- **追試・統合済**: 複数研究の整合性、バイアス、適用可能性まで精査。

## 研究メモに必須の要素

1. 原典のDOI/URL、刊行年、論文種別と調査日。
2. 年齢層、対象教科・行動、サンプル数、比較条件。
3. 実際に測ったアウトカム（テスト成績・着手率・主観評価など）。
4. 効果量・不確実性・研究上の限界（原典で確認できた場合のみ）。
5. アプリ機能への適用が『直接支持』『間接的な示唆』『設計仮説』のいずれか。
6. 中学生／大人／低年齢層への外挿の妥当性。

## 優先順位の決め方

研究の質と再現性、対象適合性、学習・生活上の重要性、利用負担、実装費用を合わせて評価。異なる結果指標の効果量を数値の大小だけで横並び比較しない。

## 注意

「最初の最小行動を決める」などの個別手法を必須とする根拠は現時点で十分ではない。行動開始支援を含む候補機能は、比較・実地試験で絞り込む。ユーザーの実名、学校、成績、家庭の記録などは研究データとしてこの公開リポジトリに置かない。
