# プロダクト構想（v0.1）

更新：2026-10-12／状態：設計仮説

## 解きたい問題

締切から逆算して予定を立てても、作業時間の見積もり違い、予定の競合、着手への抵抗、想定外の出来事によって計画が崩れる。計画の精度だけでなく、実行を支援し、現実に合わせて立て直せる道具を作る。

## 利用場面

- 日常生活：外出準備、家事、仕事、旅行の段取り、週末の予定。
- 学習：夏休みの宿題、中学生の定期試験、高校生・大人の学習。
- 時間粒度：分単位（いま何をするか）、日単位（今日の目標）、週・月単位（期限までの道筋）。

## 価値の仮説

1. 締切と使える時間を明示することで、実行可能な計画を作れる。
2. 実績を記録して見積もりを改善すると、計画倒れが減る可能性がある。
3. 行動開始支援は一律に固定せず、困りごとに応じて提示する。
4. 学習では進捗と習得の二軸を分け、復習・確認問題も予定に含める。

## 非目標（初期段階）

- 人の代わりに活動を自動実行すること。
- 行動心理学の介入効果を、アプリ未検証の段階で保証すること。
- 子どもの個人情報や成績データを公開すること。
- 既存のしゅくだいノートを一度に置き換えること。

## 成功の見方

- 計画：締切・固定予定・休息を守り、衝突と不足を明示できる。
- 実行：予定への着手・完了・延期を負担少なく記録できる。
- 学習：確認問題の正答や後日の再確認により、定着を評価できる。
- 利用性：大人と中学生の双方で、迷わず今日の行動が分かる。
