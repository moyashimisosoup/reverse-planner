# HQネコチャン v6：実画面への配置レビュー

2026-10-17。SOFT PIXEL 既存v0.2 UIの情報設計に沿って、高品質候補12種類を独立したモックで配置検証した。**これはUI配置の検証作業であり、v0.2アプリの統合や本番採用ではない。**

## 確認できたこと

- [配置候補9用途の台帳](HQ_V6_SCREEN_PLACEMENTS.csv)：最初に使う5点と柄違い・休憩候補を、既存アイコンIDで追跡。
- HOME：PC計画ネコ120px（期限の2択より上）。SETUP：メモネコ90px（フォーム見出し横）。PLAN：旗もちネコ90px（逆算タイムライン）。FOCUS：タイマーネコ120px（カウントダウンより上）。DONE：よろこぶネコ120px（明示的な完了操作後）。
- ほかの7点は代替柄/休憩表示等の候補として保持し、本採用0点のまま。
- **自己完結した単一HTMLプレビュー**と、5画面のChromiumスクリーンショットを作成。レビュー画面では5画面切替、背景色3種、表示サイズ64〜160px、場面ごとの猫差替を操作できる。
- headless Chromium 320/390/1280px、画面5種のレンダリング、PNGの自然幅、横はみ出しなし、暗色背景・サイズ・柄差替・UI押下、例外なしを確認。390pxでTabフォーカスとReduced Motionも確認し、**31個のブラウザチェック成功**。
- HOMEに進捗バーが表示される試作側の不具合を修正し、再検証。未公開のHTMLのみの変更。

ローカル成果物：`reverse_planner_cat_ui_preview_v6.html`（PNG 12点を内蔵）、`reverse_planner_cat_ui_screen_review_v6.zip`（画面キャプチャ・HTML・素材・配置台帳・テスト記録）。

- iPhone Safari実機、200%文字拡大、VoiceOver、GitHub Pages配信、ユーザーデータとの互換は未検証。
