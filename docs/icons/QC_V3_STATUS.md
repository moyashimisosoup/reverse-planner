## 取り扱い上の注意

- 自動的な画像生成・切り抜きは品質保証ではない。192〜256pxでも表示に適した形へ調整・目視確認が必要。
- 元画像12枚・背景付き候補196件・透過試作16件の**PNGバイナリは現時点でGitHub未保存**。現物を含む検品用ZIPを会話で引き渡す。
- 透過に失敗した例は、白いネコの体が背景色と誤認され、濃色背景で消える。修正前の透過候補をアプリに採用しない。
- レビュー用の単一HTMLはコンテンツを埋め込んだ約6MBのローカル検品画面。ブラウザ自動操作は環境側アクセス制限で未検証。静的IDとデータ件数、JavaScript構文を確認済み。
- 不採用・差替を含む結果はIDを変更せず台帳で管理。画像本体を保存する場合は原本上書き禁止。
- 続く作業は、ブラウザでのレビュー動作テスト、残る白猫マスクの手修正、ライセンスと小サイズ視認性確認後に本採用を選定。
