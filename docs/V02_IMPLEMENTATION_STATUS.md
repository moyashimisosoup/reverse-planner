## 今回実装済み（レビュー待ち）

- HOME：『何時まで？』『何日まで？』の2択と、保存済み計画の続き。
- SETUP：日時入力、編集可能なタスク、任意のサンプル、折りたたみ詳細設定。
- PLAN：逆算結果・タイムライン・不足時間の表示・締切延長の提案。
- RUN：現在の作業、時刻モードの簡易タイマー、タスク完了、日割りの今日分の表示。
- デザイン：SOFT PIXEL配色・カード・2〜4px立体影、沈むボタン、画面スライド、追加タスクと完了時の軽い演出。
- 保存：v0.1の`reverse-planner:prototype:v1`・4シート・タイマー形式を保持。新規開始は空の計画。
- 異常データ：既存の不正保存データは無断上書きせず、元データのテキスト書き出し・確認付き初期化。
- GitHub Actions：PRでテスト、mainでテスト後GitHub Pagesデプロイ。新規`assets/state.mjs`を配信対象に追加。

## 実施した開発環境内の確認

- `assets/app.js`、`assets/state.mjs`、`assets/core.mjs`のJavaScript構文チェック。
- 主要HTML要素とJS参照IDの照合。
- 旧保存データの読戻し・将来向け任意フィールドの保持・破損JSON判定。
- モックDOMを使用した、HOME→SETUP→PLAN→RUN→タイマー→完了→日付/学習テンプレートへの切替を含む10項目の簡易操作試験。
- 既存`tests/core.test.mjs`と新規`tests/ui-v02.test.mjs`をGitHub Actionsで実行する設定。

**CI検証結果（2026-10-17）**：[GitHub Actions run #38975790649](https://github.com/yama-books/reverse-planner/actions/runs/38975790649) で単体テスト19件とChromiumの操作試験32チェックが成功。現行の追加試験もPRで実行中。320/390/1280pxのホーム、320pxの入力・結果・実行、時間/日付両ルート、タイマー、旧v0.1データと未知フィールド保持、Reduced Motionを確認した。

**ブラウザ検証と実機検証は別**。Chromiumの自動化はPC上でのビューポート検証であり、iPhone Safari実機のタップ/保存/描画の品質を保証しない。日本語フォントはActionsのテスト環境だけに導入（アプリにフォントファイルは同梱しない）。

**画面レビュー結果**：狭いヘッダーの13px横はみ出しと、時計タイムラインの日時の重複折り返しを修正。実画面のキャプチャをGitHub Actions Artifacts（v02-ui-screenshots、7日保持）として保存。旧4シートからの任意再開導線を追加。
