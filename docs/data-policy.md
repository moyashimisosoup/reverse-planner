# データ・公開運用ポリシー（初期）

更新：2026-10-12／状態：開発時ガイドライン

## 公開してよいもの

- 一般化した仕様、匿名の例題、研究の書誌情報と短い独自要約。
- 個人を特定できないテスト用のダミーデータ。
- 秘密情報を含まないコード・テスト。

## 公開しないもの

- APIキー、認証情報、合言葉、環境変数の実値。
- 児童・生徒の氏名、学校、学習成績、スケジュール、家庭の実データ。
- 実利用者の操作ログ、個人に紐づく先延ばし・気分等の情報。
- 再配布権限を持たない論文PDF・教材・書籍のスキャン。

## 機能実装時の原則

- 最初は実名登録なしでも使えることを検討。データ保存・共有の同意と範囲を明示。
- 利用者端末上の保存と共有ストレージの責任境界を区別する。
- テスト用データと本番データを混在させない。
- 誤削除を避ける書き出し・復元・バージョン管理を検討。
- 未成年者の学習データを共有する場合は権限と目的を限定。

## 事故対策

公開リポジトリに秘密情報を誤コミットした場合、ファイル削除だけでなく鍵の失効・ローテーションと履歴への対処が必要。Git履歴は公開後の削除だけで消えるとは限らない。
