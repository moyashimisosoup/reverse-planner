# v0.1 Web試作版（2026-10-17）

## 操作できること

- **くらし／まなび**：用途別の入力サンプルを切り替える。両者は独立した計画として保持する。
- **時刻から逆算**：終了日時・作業時間・予備時間から開始時刻と順序を計算する。未完了分のみで再計算する。
- **日付から逆算**：今日から締切日まで、使える時間と休む曜日・予備日を指定して、日ごとに時間を割り当てる。
- **編集・記録**：作業追加、改名、所要時間変更、順序変更、削除、完了チェック。
- **試作タイマー**：時刻モードの作業を選んで開始、一時停止、5分追加、完了を記録。
- **端末内保存**：ローカルストレージへ自動保存。JSONを書き出して個人でバックアップできる（読み込み機能はまだない）。

## 公開・実行

依存ライブラリやビルドは不要。静的な index.html と assets/ 配下のCSS/ES Modulesで動作する。
GitHub Pagesは **Settings → Pages → Source: GitHub Actions** を使用する。公開URLは **https://yama-books.github.io/reverse-planner/**。ワークフローは [`.github/workflows/deploy-pages.yml`](../.github/workflows/deploy-pages.yml) で、テスト、最小静的ファイルの作成、Pagesへの配信を行う。2026-10-17にデプロイ成功と公開ページHTTP 200を確認済み。実機での操作確認は別途必要。

ローカルではモジュール読み込みのため簡易HTTPサーバー（例：python -m http.server 8000）で開く。file:// 直開きはブラウザにより制限される。
計算コアのテスト：Node.js（18以降）で `node --test tests/core.test.mjs`。

## 仕様上の重要な境界

- v0.1は**時間配分の試作**。学力・理解度を測定したり、学習法の効果を保証するものではない。
- 作業は入力順に配置する。分割可能性、作業間の依存関係、並行作業、固定予定の重複回避は未実装。
- 日割りは作業時間を均等に近づける簡易アルゴリズム。1作業が複数日に分かれるため、実際の課題のまとまりに合わせて見直す必要がある。
- 日割りの期間は最大120日、1日あたり作業可能時間は5〜720分。細かな祝日・休日カレンダーは未対応。
- タイマーが時間に達しても自動で作業を完了扱いにはしない。
- 計画は端末・ブラウザ単位で独立する。ログインや端末間同期は行わない。
- JSONには計画の内容が含まれる。取り扱いは利用者が管理する。
- ページを再読み込みした際、保存されたモードと各計画の内容は保持する。
